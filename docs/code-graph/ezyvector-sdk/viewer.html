ezyvector-sdk — đồ thị mã
Lõi vector database của plugin EzyVector cho EzyPlatform: MySQL là nguồn sự thật, file theo slot để quét chính xác khi index chưa sẵn sàng, HNSW trong RAM (+ hnsw.dat) để tìm kiếm xấp xỉ nhanh.

Mỗi đường là một quan hệ do AST trích xuất (không có cạnh tự suy). Bấm một node: đường liền = node đó dùng gì, đường đứt = ai dùng nó. Khung nét đứt gom các method của cùng một class.
